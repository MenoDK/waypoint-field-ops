# Knowledge tree

A way to study something unfamiliar without loading all of it. It has a **root question** with real scale
(numbers, not adjectives), **branches** you open on demand, and a **maturity curve** that moves only on evidence.

- Open only the branch you need. The rest stays closed and costs nothing.
- A branch earns a higher maturity level by _evidence_ (a measurement, a passing test, a production fact), never by time spent.
- YAGNI applies to study too: do not open a branch for something no task needs yet.
